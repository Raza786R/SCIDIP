# HE-MCGA — High-Entropy Metal-Ceramic Gradient Architecture

An AI-driven inverse design platform that discovers optimal Refractory High-Entropy Alloy (RHEA) compositions and Functionally Graded Material (FGM) coating architectures for aerospace turbine blades, targeting the Safran Explore Smart Materials Program 2026 (Challenge 2).

The platform screens the Mo–Nb–Ta–W–Cr (+ V, Ti, Zr, Hf) compositional space using empirical thermodynamic filters, ML property surrogates, and a 1D reduced-order FEA solver to identify alloy + gradient combinations that survive 10,000 thermal cycles from 300 K to 1400 K.

---

## Tech Stack

| Layer | Tools |
|---|---|
| Language | Python 3.10+ |
| Data / ML | pandas, numpy, scikit-learn (RandomForest, GradientBoosting, StandardScaler) |
| Optimisation | scipy.optimize (differential_evolution, minimize_scalar) |
| Bayesian surrogate | scikit-learn GaussianProcessRegressor (Matérn kernel) |
| Thermodynamics | pycalphad + TCHEA4.TDB (optional, falls back to Gibbs proxy) |
| FEA surrogate | Custom 1D tridiagonal thermoelastic solver (numpy — no FEniCS needed for screening) |
| Sustainability | AlloySustainability (Gorsse 2025 model — optional) |
| Datasets | Materials Project API (mp-api), OQMD REST, JARVIS-DFT OPTIMADE |

## How To Run — Full Pipeline End to End

> **Prerequisites:** Python 3.10+, pip packages: `pandas numpy scikit-learn scipy mp-api requests urllib3`
> Optional: `pycalphad` (for real CALPHAD), `AlloySustainability` (for sustainability stage)
> **Run all commands from the repo root directory.**

### Step 1 — Fetch raw DFT data from public databases

```bash
python scripts/fetch_datasets.py
```

Writes: `data/raw_materials_project.csv`, `data/raw_oqmd.csv`, `data/raw_jarvis.csv`, `data/combined_raw_data.csv`

Needs the Materials Project API key in `bin/api.txt` (key already present: `nREzcJl7KZF5PZl1FIXCMbCSTbxQ55Ii`).

---

### Step 2 — Compute intermediate properties

```bash
python scripts/calculate_properties.py
```

Reads: `data/combined_raw_data.csv`
Writes: `data/processed_candidate_properties.csv`

Computes elastic modulus (Voigt), Poisson's ratio, Debye temperature, Grüneisen parameter, Slack-model thermal conductivity, rule-of-mixtures CTE. Drops intermediate (Category E) columns from the final output.

---

### Step 3 — Generate the full fractional composition grid

```bash
python scripts/generate_compositions.py
```

Writes: `data/all_compositions-generated.csv` (10,626 rows, Mo–Nb–Ta–W–Cr at 5% increments)

---

### Step 4 — Apply Miedema empirical stability filters

```bash
python scripts/empirical_filter.py
```

Reads: `data/all_compositions-generated.csv`
Writes: `data/stable_compositions.csv`

Filters on δ ≤ 6.6%, ΔHmix ∈ [−15, +5] kJ/mol, VEC ∈ [4.0, 6.8], Ω ≥ 1.1.
**Known issue:** All 10,626 compositions currently pass — the five Mo/Nb/Ta/W/Cr elements are too similar for these criteria to reject anything. The filter is not actually filtering.

---

### Step 5 — Train ML surrogates and predict properties for all compositions

```bash
python scripts/train_composition_ml.py
```

Reads: `data/processed_candidate_properties.csv` (or falls back to synthetic data), `data/stable_compositions.csv`, `data/EXP-MPEA_dataset.csv`
Writes: `models/ml_predictions.csv`, `models/composition_model.pkl`

Trains a `RandomForestRegressor` for bulk modulus prediction and a `GradientBoostingRegressor` (transfer-learning weighted) for yield strength. Appends predicted CTE and thermal conductivity (rule of mixtures) to all 10,626 compositions.

**Known issue:** If real DFT data is insufficient, training falls back entirely to synthetic Rule-of-Mixtures data. The reported R² = 0.97 reflects internal consistency on synthetic data, **not** real-world accuracy.

---

### Step 6 — Score all compositions through the 1D FEA and rank

```bash
python scripts/evaluate_candidates.py
```

Reads: `models/ml_predictions.csv`
Writes: `models/top_50_candidates.csv`

For every true HEA, runs 1D thermoelastic surrogate across 4 ceramics × 4 gradient exponents. Keeps only those with safety factor ≥ 1.45. Sorts by minimum interface stress.

**Note on pathing:** `evaluate_candidates.py` resolves its input as `Path(__file__).parent.parent / 'models' / 'ml_predictions.csv'`. With the script living in `scripts/`, `parent.parent` resolves to the repo root, making the full path `root/models/ml_predictions.csv` — which is correct given the actual folder structure.

**Known issue:** `top_50_candidates.csv` is currently empty, meaning this step either was not run to completion or the SF ≥ 1.45 filter rejected all candidates. The underlying cause is that the `predicted_yield_strength_MPa` values from the synthetic-data-trained model are unreliable, producing safety factors that may not meet threshold. Re-running after improving Step 5 data quality is required.

---

### Step 7 — Generate the manufacturing layer recipe for the #1 candidate

```bash
python scripts/generate_manufacturing_recipe.py
```

Reads: `models/top_50_candidates.csv`
Writes: `models/top1_manufacturing_recipe.csv`

Expands the best candidate into 11 discrete depth-composition layers using the optimal gradient exponent. Run from the repo root so the `os.path.join('models', ...)` path resolves correctly.

**Current state:** The recipe on disk was generated from a stale run and shows `Mo0.05Nb0.80Ta0.05W0.05Cr0.05` — a composition with 80% Nb that violates the HEA definition (max per element should be ≤ 35%). This recipe is invalid and must be regenerated after fixing Step 6.

---

### Optional — Phase validation (Gibbs proxy, no TCHEA4 needed)

```bash
python phase_wise_analysis/phase1_calphad_phase_validation.py
```

Evaluates the final composition against VEC, δ, and a Gibbs free energy proxy sweep. Produces a validation plot at `phase_wise_analysis/day1_calphad_validation_curve.png`.

---

### Optional — Full CALPHAD (requires TCHEA4.TDB licence)

```bash
python scripts/calphad_validation.py
```

Will warn and exit gracefully if `TCHEA4.TDB` is not present.

---

### Optional — Alternative optimisation (9-element search with constraints)

```bash
python scripts/stage1_optimizer_with_constraints.py
```

Runs differential evolution over 9 elements (Mo, Nb, Ta, W, Cr, V, Ti, Zr, Hf) with explicit penalties for high density, sigma-former excess, and Cr shortage. This is the path that produced the `Ta–W–Cr–V–Ti–Hf` family reported in the Bohrium documents. Results print to stdout only — no CSV is written.

---

### Optional — Sustainability screening

```bash
pip install AlloySustainability
python scripts/stage5_sustainability.py
```

Uses the Gorsse 2025 framework on the hardcoded `Ta–W–Cr–V–Ti–Hf–Al` composition.
